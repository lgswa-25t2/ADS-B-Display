# ✈️ ADS-B Display 사용자 가이드

## 🎯 이 프로그램은 무엇인가요?

**ADS-B Display**는 **실시간으로 항공기 위치를 지도에서 볼 수 있는 프로그램**입니다.
- 📍 전 세계 항공기들이 어디를 날아가고 있는지 실시간으로 확인
- ✈️ 각 항공기의 상세 정보(항공편명, 고도, 속도 등) 표시
- 🗺️ 다양한 지도 배경으로 보기 가능
- 📊 항공기 이동 경로 추적 및 분석
- 🎮 플레이백 기능으로 과거 데이터 재생

## 🚀 요약 가이드

### 1단계: 데이터 연결하기
```
🔗 가장 쉬운 연결 방법
1. 오른쪽 패널에서 "SBS Connect" 버튼 찾기
2. IP 주소 입력란에 "data.adsbhub.org" 입력 (기본값)
3. "SBS Connect" 버튼 클릭
4. 버튼이 "SBS Disconnect"로 바뀌면 연결 성공! ✅
```

### 2단계: 항공기 보기
- 연결되면 몇 초 후 지도에 항공기들이 나타납니다 🛩️
- 각 항공기는 컬러 점과 화살표로 표시됩니다

### 3단계: 항공기 정보 확인하기
- 지도의 항공기를 **마우스 우클릭**하면 추적 시작
- 오른쪽 패널에 항공기 상세 정보가 표시됩니다

| 라벨 | 표시 내용 | 형식 |

| 라벨 | 표시 내용 | 단위 |
|------|----------|------|
| **SPD** | 속도 + 수직속도 | "450.00 KTS VRATE:1200.00" |
| **HDG** | 항로각 | "090.00 DEG" |

| **Certificated Info** | 인증 정보 |
| **Expiration Data** | 만료일 |

## ⏯️ 플레이백 기능

### **플레이백 제어 (파일 재생 시에만 표시)**

#### **속도 조절 패널**
- **위치**: 화면 우상단
- **속도 범위**: x1 ~ x10
- **기능**: 재생 속도를 실시간으로 조절

#### **진행률 제어 패널**
- **위치**: 화면 우하단
- **기능**:
  - 현재 재생 시간 표시
  - 전체 재생 시간 표시  
  - 진행률 바로 원하는 위치로 점프
  - 드래그로 시간 탐색

### **플레이백 모드에서만 적용되는 기능**
- **PurgeOldHistory**: 30초 동안 업데이트되지 않은 항공기 경로 자동 삭제
- **시간 기반 데이터 정리**: 실시간 모드와 달리 시간 기준으로 데이터 관리

## 🔍 필터 기능

### **항공기 타입 필터**
```
드롭다운 메뉴: "All" (기본값)
├── All: 모든 항공기 표시
├── Helicopters: 헬리콥터만 표시  
├── Military: 군용기만 표시
├── Known Civilian: 등록된 민간기만 표시
└── Unknown: 타입 불명 항공기만 표시
```

### **고도 필터 (AltitudeFilterComboBox)**
- **범위**: 사용자 정의 고도 구간별 필터링
- **표시**: Consolas 폰트, 굵게 표시

### **속도 필터 (SpeedFilterComboBox)**  
- **범위**: 사용자 정의 속도 구간별 필터링
- **표시**: Consolas 폰트, 굵게 표시

### **지역 필터 (Area Filter)**
- **다중 선택**: Ctrl+클릭으로 여러 지역 동시 선택
- **단일 선택**: 일반 클릭으로 해당 지역만 선택
- **해제**: ESC 키로 모든 선택 해제
- **적용**: 선택된 지역 내의 항공기만 표시

## 📍 지역(Area) 관리

### **지역 생성**
1. **Insert** 버튼 클릭 → 삽입 모드 활성화
2. 지도에서 **마우스 우클릭**으로 점 추가
3. **Complete** 버튼으로 영역 완성
4. **Cancel** 버튼으로 취소

### **지역 목록 관리**
| 조작 | 기능 |
|------|------|
| **단일 클릭** | 해당 지역만 선택 |
| **Ctrl + 클릭** | 지역 추가/제거 선택 |
| **ESC 키** | 모든 선택 해제 |
| **Delete 버튼** | 선택된 지역들 삭제 |

### **지역 표시**
- **경계선**: 지역 색상으로 표시
- **내부**: 반투명 색상으로 채우기
- **선택 상태**: 점선 경계로 강조 표시

## 🔧 문제 해결

### **일반적인 문제**
| 문제 | 해결 방법 |
|------|----------|
| **항공기가 표시되지 않음** | SBS/Raw 연결 상태 확인 |
| **지도가 로드되지 않음** | 인터넷 연결 및 지도 타입 확인 |
| **플레이백이 멈춤** | 파일 형식 및 경로 확인 |
| **필터가 작동하지 않음** | 필터 설정 재확인 및 데이터 새로고침 |
